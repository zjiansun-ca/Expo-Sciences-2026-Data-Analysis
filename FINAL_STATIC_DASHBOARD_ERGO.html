Simulation Architecture

ERgo advances in discrete 1-hour steps. Each tick: wait counters increment, treatment durations count down, discharges are processed, and the waiting queue is re-sorted per active policy.


System utilization is calibrated using the Erlang-C model: ρ = λ / (c × μ) ≈ 0.99, reflecting near-saturation conditions observed in MSSS data.


A 600-hour burn-in precedes each 600-hour analysis window to allow organic queue formation under each policy, avoiding startup bias.

Key Design Decisions

Misclassification Rate: A 10% random triage error is injected per patient to reflect real-world triage uncertainty documented in Ding et al. (2018).


Congestion Penalty: When all beds are occupied, a 10–20% treatment speed penalty is applied, modelling staff overload at capacity.


Data Sources: Arrival rates (λ) are empirically derived from MSSS hourly ER status reports (RVH/MCH) and AHS operational data (UAH). The queue's priority score is computed per active policy each tick.
